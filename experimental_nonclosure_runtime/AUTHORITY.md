# Experimental Non-Closure Runtime

This package is an isolated experiment and is not part of CURRENT, the
independent runtime v2, or the False Sufficiency Generality Gate.

Its frozen local semantic criterion is:

> No finite representation can authorize by itself the closure of the reality
> it represents.

Every result is therefore a pair produced together:

1. a human-readable local closure, valid only within the explicit support; and
2. a specific first unsupported continuation derived from that closure. It names
   the origin fragment, unsupported relation, missing discrimination, dependency
   frontier, and a concrete next question.

The local closure exists to explain and operate on the available support. It is
not a closure of the represented reality. A local fragment endpoint is not the
endpoint of its consequences or of mechanical continuation.

The same non-closure contract applies recursively to represented fragments,
runtime subjects, rules, and tests. The only result statuses are:

- `SUPPORTED_LOCAL`
- `REOPEN`
- `UNRESOLVED`

There is no global-pass state in this experiment.

No result is complete unless its local closure and open frontier are both
present and mutually bound in the receipt. The frontier is the mandatory
counterpart of every explanation.

A generic unknown, a free-form reopen label, or a caller-authored question is
not a valid first continuation. The runtime derives the `SpecificOpening`
from the local closure and rejects any result whose opening does not match that
derivation.
