# PHI-INFINITY AMENDMENT 03
# ACCESS REPRESENTATION AND RELATIONAL INTEGRITY

**Status:** AUTHORITATIVE SUCCESSOR AMENDMENT

THIS AMENDMENT ADDS NO NEW FUNDAMENTAL CAUSAL OPERATION.

Its role is only to formalize faithful representation of accessible evidence
before generative M execution. It does not modify the frozen Mother Mechanics,
the Fundamental Laws, or Amendment 02.

## 1. Access package

Each M execution operates on one explicitly scoped access package \(a\).

The access package is representational substrate. It is not:

- an ontological world;
- an absolute event;
- an absolute time;
- a permanent domain;
- a causal model.

Package membership is determined only by the supplied package and its exact
local referential structure. Evidence discoverable outside the package does
not become accessible under \(a\) automatically.

## 2. Access-local referents

An access package may contain opaque local handles. A local handle has no:

- semantic meaning;
- ontological identity;
- persistent identity;
- cross-access identity;
- causal meaning;
- mechanical meaning;
- category meaning.

Its only permitted role is exact local referential integrity within package
\(a\). The same token text in another access package is not the same referent
unless a separate relation is supplied.

## 3. Local binding

For a local reference \(r\) and supplied manifestation record \(x\):

\[
\operatorname{Binds}_a(r,x)
\iff
\operatorname{ReferentMap}_a(r)
=
\operatorname{AccessRecord}_a(x)
\]

The equality above means only identity of the supplied record reference inside
access package \(a\). It does not mean ontological identity.

An absent, ambiguous, multiply resolving, or otherwise unresolved reference
produces `UNRESOLVED`. The machine must not search, match, infer, approximate,
or substitute a record.

## 4. Access membership

For a witness \(w\):

\[
\operatorname{AccessibleUnder}_a(w)
\]

is true only when \(w\) is directly contained in package \(a\), or is exactly
referenced through that package's local referential structure.

Package membership adds no transformation, dependency, exchange, causation,
selection, or semantic interpretation.

## 5. Origin provenance

Origin provenance records only how a witness entered the execution package.
The permitted statuses are:

- `SUPPLIED_AS_ACCESS_STRUCTURE`;
- `DERIVED_AFTER_ACCESS`;
- `ORIGIN_UNRESOLVED`.

These statuses do not mean true, false, trusted, untrusted, causal,
mechanically relevant, or permanently valid. The M-machine preserves supplied
provenance; it does not infer or certify origin.

Missing or ambiguous origin is `ORIGIN_UNRESOLVED`.

## 6. Direct access relation witness

\[
\operatorname{Connects}_a(w,x,y)
\iff
\operatorname{AccessibleUnder}_a(w)
\land
\operatorname{Binds}_a(\operatorname{endpoint}_1(w),x)
\land
\operatorname{Binds}_a(\operatorname{endpoint}_2(w),y)
\land
\operatorname{Origin}_a(w)
=
\texttt{SUPPLIED\_AS\_ACCESS\_STRUCTURE}
\]

This is an access-level relation-witness qualification only. It does not
imply:

- dependency;
- exchange;
- interaction;
- causation;
- mechanical relevance;
- ontological identity;
- ontological separation.

The absence of `Connects` does not imply absence of a real relation.

## 7. Access-integrity boundary

Access-integrity lookup is not an M-generative transformation. Every
access-integrity receipt is typed as `ACCESS_INTEGRITY` and identifies this
amendment as its provenance.

Access-local referents, package membership, and origin provenance preserve only
the supplied access structure. They do not create missing relations or
continue the M trajectory.

The raw M executor stops after relation qualification at the
`DISCRIMINABILITY_FRONTIER`. It does not emit `Delta`, dependency, exchange,
causal, relevance, or continuation results from this amendment.
