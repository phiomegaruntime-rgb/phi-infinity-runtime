# M Derived Clarification: Continuity Structure Rule

Version: 1
Status: DERIVED_CLARIFICATION
Rule identifier: M_RULE_CONTINUITY_STRUCTURE_V1

This document is a derived clarification of the frozen Mother Mechanics
grammar. It does not amend, replace, or rewrite any frozen Mother Mechanics
document. It is admitted only after the frozen authority boot succeeds.

The rule distinguishes a continuous transformation from a change in the
structure of a fragment's continuity. It operates on an explicitly supplied,
mechanically discriminated genealogy relation between a prior configuration
and a successor configuration. It does not reconstruct that relation.

A fragment continues as one continuity when exactly one non-reducible
continuation class, supported by the prior genealogy, is supplied.

When complete discriminating access establishes that no continuation of the
prior genealogy exists, that prior continuity has ceased.

When complete discriminating access establishes more than one continuation
class that cannot be reduced to one class, the result is branching or
non-unique identity.

When more than one antecedent continuity is explicitly supplied as converging
on one continuation class, the result is fusion or a new composite
continuity.

The classification is based only on explicit mechanical genealogy
relations, their supplied discriminability status, and their receipt-bearing
ancestry. Percentages of matter, resemblance, form, function, human names,
labels, payloads, timestamps, plausibility, scores, and arbitrary thresholds
are not generative criteria.

The epistemic boundary is mandatory. If available access does not
discriminately establish uniqueness, absence, or multiplicity of continuation,
the only authorized result is UNRESOLVED. UNRESOLVED cannot be converted into
continuity, cessation, branching, non-unique identity, fusion, or composite
continuity by estimation, preference, completion, or human interpretation.

The real rule is separate from later human coding. A human name does not
create continuity, and changing a human name does not create discontinuity.
Human coding may describe a result after the rule, but it is not a premise of
the rule and cannot change its result.

The rule is falsifiable at its declared access boundary: changing the exact
supplied genealogy relation from one continuation class to none, multiple
non-reducible classes, or one class with multiple antecedents must change the
authorized classification accordingly. Removing the discriminating access
must instead produce UNRESOLVED.

No conclusion is authorized when the supplied evidence is malformed,
unprovenanceable, or lacks its receipt chain. Such an invalid proposal is
blocked rather than repaired.
