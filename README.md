## Core Invariants & Architecture (`src/`)

* **`core.py` (Substrate Engine):** 6 primitive invariant equations, antisymmetric tanh-mediated state flows, local proper-time metric (dtau), and stress-induced dynamical force inversion (1 - beta * R_i).
* **`membrane.py` (Membrane Evaluator):** Emergent boundary persistence metric (M_C) computing topological cohesion against environmental dissipation.
* **`gating.py` (Deterministic Multi-Access):** Ex-ante deterministic gating protocol (`FirstDivergence`) with strict trace-locking and state-space `REOPEN` recovery.
* **`demo.py`:** Standalone multi-metric diagnostic and plotting pipeline.
